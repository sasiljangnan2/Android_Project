# 테스트 영상 촬영

Firebase 설정 없이 기본 시연 모드로 실행한다. 로그인 화면의 **시연 계정으로 둘러보기**를 누르면 내 모집·참여·채팅 기록이 채워진 촬영용 계정으로 들어간다. 새로 회원가입한 계정에는 촬영 계정의 개인 모집·채팅을 붙이지 않는다.

이미 앱을 실행 중이었다면 Hot Reload 대신 **Hot Restart**하거나 앱을 완전히 종료한 후 다시 실행한다. 시연 데이터는 메모리에만 있으며 재실행하면 처음 상태로 돌아온다. 마감은 실행 시점 기준으로 다시 설정된다. 실제 대학이나 거래 정보가 아닌 샘플이다.

## 촬영 순서

1. 로그인 화면 → 회원가입 입력 검증 또는 가입 흐름을 촬영한다. 가입을 촬영했다면 마이에서 로그아웃한다.
2. **시연 계정으로 둘러보기** → 주변 모집. 반경 500m는 1건, 1km는 4건, 2km는 8건이다. 실제 GPS 대신 기본 **대학 정문 기준**을 사용한다.
3. **달걀 30구 같이 나눠요** → 모집에 참여하기 → 참여 확정하기. 2/3명에서 3/3명이 되어 매칭 완료 화면을 촬영한다.
4. 참여자 채팅으로 이동해 메시지를 직접 보낸다. 이 모집의 채팅은 새 대화로 시작한다.
5. 내 모집 → 내가 연 모집에서 모집 중·매칭 완료·모집 취소 필터를 보여준다.
6. 내 모집 → 참여한 모집 → **설향 딸기 2팩 함께 사요** → 참여 취소 확인을 촬영한다.
7. 채팅 탭 → **주말 아침 달걀 같이 나눠요**. 미리 넣은 상대/내 대화 4개와 직접 답장하는 모습을 촬영한다.
8. 2km 목록 또는 내 모집에서 취소된 딸기 모집 상세를 열어 종료 상태를 보여준다.

다시 같은 장면을 찍으려면 앱을 완전히 재실행한다. 영상 자체의 녹화는 Android Studio 에뮬레이터 또는 사용 중인 화면 녹화 도구에서 진행한다.

원본 데이터는 `lib/features/recruitment/data/demo_data.dart`에 있다. Firebase 저장소·인증·권한 계약에는 적용하지 않는다. 매칭은 모집 완료이며 실제 구매·결제 완료를 뜻하지 않는다.
