## 공통 상태
- 로딩: 진행 표시 및 중복 버튼 차단.
- 빈 결과: 성공 응답이 빈 배열일 때만 빈 목록 표시.
- 목록 실패: 이전 결과가 있으면 오래된 결과임을 표시하며 상세·등록 진입 차단.
- 상세/참여 실패: 결과 미확인임을 안내하고 최신 재조회 전 신청·취소 차단.
- 등록 실패: 입력과 동일 요청 ID 유지. 미확인 이후 편집을 잠가 같은 요청의 내용 변경을 막는다.
- 지도 실패: 지도 로드 확인 전/타일 오류 후 확정 버튼 차단, 뒤로 이동 후 재시도.
- 사진 실패: 상세 대체 표시와 새로고침. 업로드 실패 시 모집 생성하지 않음.
- 위치 권한 거부·5초 실패: 정문으로 전환하고 현재 기준점을 표시.

## 디자인 기준
초록색(함께 구매)과 아이보리 바탕. 한 화면에 하나의 주된 행동을 강조한다.
모집 상태를 색만으로 구분하지 않고 문자로 표시한다. 예상 비용을 결제 금액으로 표현하지 않는다.
카드에는 제품·상태·인원·예상 비용·수령 거리를 우선 배치한다.
좁은 모바일 화면을 기본으로 하되 웹에서는 본문 폭을 제한한다.
