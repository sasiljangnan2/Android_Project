## 확인 시트와 이동

P01 기준점, P02 참여, P03 취소, P04 등록 완료, P05 참여자, P06 앱 내 알림, P07 작성 종료를 구현했다. 참여/취소 확인 전에는 요청하지 않는다. 알림에서 상세로 이동할 때 서버에서 다시 조회한다. FCM 푸시는 후속 구현이다.

네 탭의 필터·스크롤을 유지한다. 상세를 닫으면 들어온 탭의 목록을 갱신한다. 탭 루트에서 뒤로 가면 주변 모집, 주변 루트에서는 종료 확인이다. 등록은 이전 단계 값을 유지하고 전체 종료를 확인한다. 저장 중에는 결과 확인을 안내하며 성공 시 내가 연 모집으로 이동한다.

## 오류와 데이터

- 목록의 로딩/정상 빈 결과/오류를 구분한다. 조회 실패는 목록을 비우고 재조회 동작을 제공한다.
- 상세 삭제·실패는 재조회/목록 복귀를 제공한다. 참여 응답 유실은 성공으로 가정하지 않으며 재조회 전 참여·취소를 막는다.
- 등록 응답 유실 시 내용·요청 ID를 잠그고 uid_requestId로 재조회한다. 없으면 같은 요청을 재시도한다. 명확히 거부된 경우에만 새 ID로 편집한다.
- 채팅 조회/전송 오류를 구분한다. 미확인 전송의 원문·ID를 유지한다. 조회 실패 중에는 새 메시지를 보내지 않는다.
- 위치 취득 5초 초과/권한 거부는 정문으로 전환하고 이유를 알린다. 정문 2km와 검색 반경의 교집합만 직선거리로 표시한다.

## 디자인과 접근성

라임 `#D5F45B`, 초록 `#173E2D`, 아이보리 `#F7F8F2`, 오류 `#B4232A`, 로컬 Pretendard. 본문 최대 640dp, 여백 20dp, 카드 간격 12dp. 주요 버튼 52dp, 아이콘 버튼 최소 48dp. 상태는 문자로 표시한다. 시스템 다크 모드·글자 확대를 따르며 큰 글씨에서는 카드 사진·본문을 세로로 배치하고 본문 전체를 스크롤한다.

## 영상 촬영 화면 표현

사용자 요청으로 로그인·회원가입·목록·마이·알림·종료 확인에서 시연/샘플/연결 준비 안내를 제거했다. 빠른 진입 버튼은 **바로 시작하기**, 계정 설명은 **이메일 계정**, 장소는 정문 앞·학생회관 앞 등 일반 이름으로 표시한다.

기본 데이터 공급자는 계속 메모리 DemoRepository다. 실제 Firebase 연결 여부나 실패 처리·데이터 보존 정책을 바꾼 것이 아니다. 촬영용 계정과 모집은 앱 프로세스 종료 시 초기화되며 실제 클라우드 계정·거래·푸시를 생성하지 않는다. 이 구분과 미검증 범위는 개발 문서에서 유지한다.
